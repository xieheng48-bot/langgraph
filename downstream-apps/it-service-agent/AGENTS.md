# IT 服务台下游应用工作约定

本文件只作用于当前应用目录。先遵守仓库根目录 `AGENTS.md`；这里补充应用自己的边界和验证方式。

## 定位与边界

- 这是应用拥有的持久化审批工作流，使用 LangGraph 运行时提供的 `StateGraph`、检查点和 interrupt/resume；不是新的核心 Agent SDK 或 harness。
- 业务改动限定在当前目录，不为演示修改上游 `libs/`、根 README、归档示例或公开运行时 API。
- 保留服务端身份/设备归属检查、审批版本及摘要校验、单任务工单唯一约束、拒绝不写工单、重启恢复能力。
- 模型只生成参考建议和已有来源 ID；不得授予它选择身份、提升权限或执行任意系统命令的能力。
- 默认离线演示，不隐藏模型或工具失败，不把模拟调用描述为真实企业集成。
- 本地部署只支持单进程，完整操作使用应用锁；若要多实例或外部 ITSM，单独设计锁、上游幂等和结果对账。
- 作者及 AI 辅助说明保持真实，不声称用户已经人工验收、生产上线或取得未测量的指标。

## 运行与测试

在当前应用目录运行：

```powershell
uv sync --group dev
uv run pytest -q
uv run uvicorn it_app.main:app --host 127.0.0.1 --port 8012
```

默认测试不得依赖真实模型或外部企业服务；使用临时 SQLite 和 httpx MockTransport。修改权限、审批、持久化或副作用时，运行对应失败/恢复测试。只改应用文档时检查命令和相对链接即可。

上述应用测试不代替根指南对上游库修改要求的 `make format` / `make lint` / `make test`。本任务不修改上游库，勿把应用测试结果描述成整个 LangGraph 仓库的验证结果。

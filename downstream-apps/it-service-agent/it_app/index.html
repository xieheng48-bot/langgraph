这个演示真正实现了什么
LangGraph 的 StateGraph 和 interrupt / Command 驱动真实流程；SqliteSaver 将暂停点保存到磁盘，重启服务后仍可审批。提案版本和摘要绑定审批，数据库用任务编号唯一约束防止重复工单。默认按关键词分类、按分类检索 SOP，没有向量检索。
